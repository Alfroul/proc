   - 对照 ADR-0011（FilterExpr）/ ADR-0016（eBPF）的 Consequences 段，确认 v0.8 落地与 ADR 一致
   - AppGroup API 签名变更是否破坏 v0.7 阶段 5 的 panel controller 边界

3. **安全性审查**
   - ebpf Linux 真实运行时权限是否正确（CAP_BPF + CAP_PERFMON 或 root）
   - FilterExpr 在 AppGroup view 聚合值是否泄漏单进程信息（如通过聚合反推）

4. **跨平台一致性**
   - v0.8 阶段 1 修的 ebpf 代码在 Windows 默认 build（无 feature）下不破坏
