## 任务清单

### 1. TD-53 改道：worker sysinfo delta 计算（~45 业务行）

**改动点 1a — `src/collect.rs`**：`SystemSnapshot` 加 `process_cache_mut(&mut self) -> &mut HashMap<u32, ProcessInfo>` 访问器（`process_cache()` 不可变版既有，对称补可变版——worker 填 speed 字段的最小开口）。

**改动点 1b — `src/mcp/handler/mod.rs` 加纯函数**（cfg `mcp-persistent-state`）：

- `pub fn compute_process_disk_speeds(processes: &mut HashMap<u32, ProcessInfo>, prev: &mut HashMap<(u32, u64), (u64, u64)>, prev_time: Option<Instant>, now: Instant)`：
  - **TUI `App::update_disk_speeds`（app.rs:1781）同款口径**：key = `(pid, start_time)`（PID 复用防护，ADR-0003）；`disk_usage` 差分 / elapsed（`max(0.001)`）；`saturating_sub`（counter 回退归 0）；无 prev 条目的进程（新出现 / PID 复用）speeds 保持 0
  - `prev_time = None`（首观测）只重建基线不填速度；`Some(t0)` 走差分
  - 尾部无条件重建 prev 基线（存活进程集合即新基线——死亡进程条目自然淘汰，TUI 同款）
  - `pub` 让集成测试可合成数据单测（不依赖真实 sysinfo）

**改动点 1c — `run_snapshot_worker`（mod.rs:293）接线**：

- worker 局部状态：`prev_disk: HashMap<(u32,u64),(u64,u64)>` + `prev_disk_at: Option<Instant>`（跨 tick，不进 handler 字段——风险 2「并发与生命周期」的规避：delta 状态 worker 私有，无锁竞争）
- 现有 `let _ = s.refresh_heavy_incremental();` 改 `matches!(..., Ok(true))` 才触发 delta（**pending tick 不重算**——TUI 只在 `Ok(true)` 分支调 `update_disk_speeds` 的同款理由：cache 未变时差分恒 0 会把速度刷成 0）
- history push / snapshot 写回 / sleep 节奏逻辑不动（步骤 3/4/5 顺序不变，delta 插在步骤 2 与 3 之间）

### 2. TD-53 改道：`metrics_disk_io` per-process 段（~35 业务行）

**改动点 2a — `src/mcp/handler/metrics.rs`**：

- `MetricsDiskIoArgs` 加 `top: Option<usize>`（None = 默认 10；schema description 写明）
- `make_metrics_disk_io_json(device, top)` 签名扩展（fallback 路径——fresh snapshot 无 delta 基线，per_process 段照常返回 top-N，速度值可能全 0，`source` 字段口径不变）
- `metrics_disk_io_json_from_snapshot(snapshot, device, top)` 加段：

```json
"per_process": {
  "source": "sysinfo-delta",
  "count": N,
  "processes": [{ "pid", "name", "read_bps", "write_bps" }]
}
```

  - 排序：`read_bps + write_bps` 降序取 top-N（`u64` 饱和加法）；**不做 device 过滤**（sysinfo per-process IO counters 是进程级聚合，无法按盘归属——schema description 声明）
  - `source: "sysinfo-delta"` 是 ADR-0035 D2 精度声明字段（Windows 下 IO counters 含非磁盘 IO 如命名管道，口径与 TUI 非管理员档一致——agent 可判读）

**改动点 2b — `src/mcp/handler/mod.rs` `proc_metrics_disk_io` tool**：description 更新（加 per_process 段与 top 参数说明）+ `args.top` 传递（snapshot 路径 + fallback 路径两处）。

**改动点 2c — `src/agent/tools/dispatch.rs:426` 机械适配**：`make_metrics_disk_io_json(str_of(args, "device"), usize_of(args, "top"))`（agent 内部分发同款参数提取，`usize_of` 既有 helper）。

**改动点 2d — `tests/test_mcp_v0_15.rs` 两处调用点**（L499 / L519）补第二参 `None`（默认 10，断言不变——per_process 是新增字段不改既有字段，手册步 11 小修范畴）。

### 4. 测试（~100 测试行，新文件 `tests/test_mcp_v0_25_stage_3.rs`）

- **TD-53 单元 ×4**（`compute_process_disk_speeds` 合成数据，不依赖真实 sysinfo）：
  1. 差分计算：proc A（pid 10, start 100）`disk_usage (1000, 2000)` + prev `(800, 1500)` + elapsed ~2s（`Instant::now().checked_sub` 构造）→ read ≈ 100 / write ≈ 250（区间断言容忍时钟抖动）
  2. 首观测：`prev_time = None` → speeds 保持 0 + prev 基线建立（第二次调用有差分）
  3. counter 回退：`disk_usage` 小于 prev → saturating 归 0 不 panic
  4. 基线重建：调用后 prev 键集 = 当前进程键集（死亡进程淘汰 + 新进程入库）；PID 复用（同 pid 不同 start_time）不命中旧条目（speeds 保持 0）
- **TD-53 响应段 ×2**（`make_metrics_disk_io_json` fallback 真实快照——结构断言不依赖系统活动）：
  5. `make_metrics_disk_io_json(None, None)`：`ok: true` + `per_process.source == "sysinfo-delta"` + `count <= 10` + 每条含 `pid/name/read_bps/write_bps` 四字段 + `total/per_disk/disks` 既有字段不缺（tool 语义不变锚——只加不改）
  6. `make_metrics_disk_io_json(None, Some(3))`：`per_process.count <= 3`（top 参数生效）
- **TD-50 运行时 ×1**（`#[tool]` 宏生成 pub 静态函数 `ProcMcpHandler::proc_smart_tool_attr()`——比 v0.17 源码 grep 静态断言更强的真实 schema 断言）：
  7. `proc_smart_tool_attr().meta` 含 `"x-deprecated": true` + `proc_metrics_smart_tool_attr().meta` 为 None（阴性对照——hint 只打废弃 tool）
- **不变锚 ×1**：
  8. `list_tool_names().len() == 46`（D4 验收锚运行时断言；TD-50 只加 hint 不删 tool / TD-53 是既有 tool 响应扩展不加新 tool）
