## 附录 E：rmcp RUSTSEC-2026-0189 暴露面评估（决策 3A 注记）

### E.1 Advisory 原文要点（rustsec/advisory-db，2026-04-29，CVE-2026-42559）

- 漏洞：rmcp <1.4.0 Streamable HTTP server transport **不校验 `Host` header** → DNS rebinding 攻击使恶意公共网站向受害者 loopback/私网接口上的 MCP server 发请求——枚举/调用 tool、读 resource/prompt、触发 tool 副作用（CVSS AV:N/AC:L/UI:R，C:H/I:H/A:H）
- **原文明确：「Non-HTTP transports such as stdio and child-process transports are not affected」**
- Patched：>= 1.4.0（默认 loopback-only host 校验）

### E.2 proc 实际暴露面（代码实证）

| 路径 | 状态 | 依据 |
|---|---|---|
| `proc mcp serve`（默认 stdio） | **不受影响** | advisory 原文；stdio 无监听 socket |
| `proc mcp serve --transport sse`（opt-in） | **理论受影响** | `serve_sse` 用 `StreamableHttpServerConfig::default()`（`src/mcp/transport.rs:200`）= 漏洞配置（无 Host 校验） |

SSE 路径攻击链需**三条件同时成立**：① 用户显式 `--transport sse`（非默认）且服务运行中；② 受害者同浏览器会话访问恶意页面；③ DNS rebinding 到 `127.0.0.1:port`。缓解在位：CLI `--bind-addr` 默认 `127.0.0.1`（transport.rs:44，全网卡 0.0.0.0 需显式 opt-in）；写操作 tool 有 confirm 契约（`confirm=false` 路径拒绝执行，test_mcp_v0_17 实证「must NOT spawn child」）。**结论：窄而真实的暴露面**——ignore + TD 追踪 0.11→≥1.4 major（46 tool 底座 breaking，独立 cycle）是当前有依据的工程判断。
