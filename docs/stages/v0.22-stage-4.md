## 已知风险（本阶段无代码改动，风险均为流程性）

### 风险 1：Cargo bump 后 Cargo.lock 漏同步

`cargo build --release` 会自动更新 Cargo.lock 的 proc 自身 version；commit 前确认 lock 文件已含 `name = "proc"` version `0.22.0`。

### 风险 2：README CLI flags 描述与代码漂移

README 措辞以 `src/cli/def.rs::AgentSub::Eval` 实装 flags（level / scenario / quick / attempts / max_steps / output / compare / provider / model）+ `SessionInfo { path }` 为准，不凭记忆写。

### 风险 3：REVIEW 数字与 eval 归档不一致

REVIEW-v0.22 中所有 E2B 数字（通过率 / 失败直方图 / 时长）以 `docs/eval/e2b-70q-v0.22.md` 为单一来源，不二次计算。
