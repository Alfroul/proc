### 3. LlmProvider trait 完整定义（~80 行业务 + ~30 行测试）

```rust
// src/agent/provider.rs
use async_trait::async_trait;
use futures::stream::BoxStream;
use crate::agent::types::{Message, ToolSchema};
use crate::agent::config::CompleteOptions;

/// LLM provider 抽象（决策 2 拍板：BoxStream + async_trait 仅 complete）
///
/// 三 impl：
/// - LlamaCppProvider（默认，本地 llama-server + OpenAI 协议）
/// - AnthropicProvider（opt-in feature = "anthropic"，云端对照）
/// - MockProvider（feature = "mock-provider"，fixture 回放，CI 用）
#[async_trait]
pub trait LlmProvider: Send + Sync {
    /// provider 标识（用于日志 / fixture 路由 / agent.toml 配置）
    fn name(&self) -> &'static str;

    /// 一次性 complete（非流式，简单场景用）
    async fn complete(
        &self,
        messages: Vec<Message>,
        tools: Vec<ToolSchema>,
        options: CompleteOptions,
    ) -> Result<CompleteResponse, LlmError>;

    /// 流式 complete（默认实现：调 complete 后包成 single-item stream，子类按需 override）
    fn stream(
        &self,
        messages: Vec<Message>,
        tools: Vec<ToolSchema>,
        options: CompleteOptions,
    ) -> ProviderStream<'static>;
}

pub type ProviderStream<'a> = BoxStream<'a, Result<Delta, LlmError>>;

#[derive(Debug, thiserror::Error)]
pub enum LlmError {
    #[error("network error: {0}")]
    Network(#[from] reqwest::Error),
    #[error("provider returned error: status={status} body={body}")]
    Api { status: u16, body: String },
    #[error("stream ended unexpectedly")]
    StreamEnded,
    #[error("model not loaded: {0}")]
    ModelNotLoaded(String),
    #[error("config error: {0}")]
    Config(String),
    #[error("io error: {0}")]
    Io(#[from] std::io::Error),
}

#[derive(Debug, Clone)]
pub struct CompleteOptions {
    pub max_tokens: Option<u32>,
    pub temperature: Option<f32>,
    pub top_p: Option<f32>,
    pub top_k: Option<u32>,
    pub stop_sequences: Vec<String>,
    /// GBNF grammar 文件内容（仅 LlamaCppProvider 用，强制 JSON 输出）
    pub grammar: Option<String>,
}

impl Default for CompleteOptions {
    fn default() -> Self { /* ... */ todo!() }
}

#[derive(Debug, Clone)]
pub struct CompleteResponse {
    pub message: Message,
    pub stop_reason: StopReason,
    pub usage: Usage,
}

#[derive(Debug, Clone)]
pub enum StopReason {
    EndTurn,
    ToolUse,
    MaxTokens,
    StopSequence,
}

#[derive(Debug, Clone, Default)]
pub struct Usage {
    pub input_tokens: u32,
    pub output_tokens: u32,
}

#[derive(Debug, Clone)]
pub enum Delta {
    /// 文本增量（assistant message 文本）
    Text(String),
    /// tool call 增量（assistant 决定调 tool）
    ToolCall(ToolCall),
    /// tool result（系统注入，告诉 LLM tool 执行结果）
    ToolResult(ToolResult),
    /// 一轮结束（含 stop_reason）
    EndTurn { stop_reason: StopReason },
}
```

## 已知风险（stage 1 实施时关注）

### 风险 1：reqwest 默认 features 拉入 openssl（与 proc 既有 rustls 路径冲突）

**mitigate**：Cargo.toml 显式 `default-features = false` + 只启用 `json` / `stream` / `rustls-tls`。

### 风险 2：async_trait 与 BoxStream 类型推导失败

**mitigate**：stage 1 写 `ProviderStream` 类型别名（`pub type ProviderStream<'a> = BoxStream<'a, Result<Delta, LlmError>>`），避免 trait method 签名里直接写复杂类型。

### 风险 3：GBNF grammar 文件 include_str! 路径错

**mitigate**：用相对路径 `include_str!("../agent/grammars/tool_call.gbnf")`（从 src/agent/grammars/mod.rs 看是 `tool_call.gbnf`）。

### 风险 4：cfg-gate 误关导致 --no-default-features 编译失败

**mitigate**：每个 provider 文件顶部加 `#[cfg(feature = "...")]`，mod.rs 用 `#[cfg(feature = "...")] pub mod ...`。stage 1 验收标准 #2 强制 `--no-default-features` 编译通过。
