### 阶段 2：Slice — Linux 代码移除（最大 Slice，可能触发 Checkpoint）

> **独立会话指令**：`阅读 CONTEXT.md、docs/stages/v0.12-stage-2.md、docs/stages/v0.12-stage-2-audit.md、docs/adr/0022-windows-only-platform.md，移除全部 Linux/macOS 代码`

**目标**：按 stage 1 audit 报告移除全部 Linux/macOS 代码——删整模块（src/ebpf/ + src/psi.rs）+ 清理 ~30 文件 cfg gate + 删 Linux-only tests + 更新 CI + 更新 README 平台表。本阶段是 v0.12 cycle 最大 Slice，预期 ~1000 行删除 + ~200 行调整。

**前置依赖**：阶段 1 已完成（ADR-0022 Accepted + Cargo.toml feature 清理 + audit report 已产出）。

**依赖测试**（开工时跑这些测试的详情）：
- `cargo test --release -q`（summary，应 ≥ 1146 passed）
- `cargo test --release --test test_filter_expr_v2 -- --nocapture`（含 FlowSource.Ebpf 测试，本阶段会移除）
- `cargo test --release --test test_ebpf_flow -- --nocapture`（本阶段会删除此文件）

**任务清单**：

1. **删除整模块**（按 audit 报告，无业务保留）
   - `rm -rf src/ebpf/`（6 files：mod.rs / flow.rs / worker.rs / stub.rs / elf_loader.rs / ebpf-ebpf/）
   - `rm src/psi.rs`
   - `rm tests/test_linux_stubs.rs`
   - `rm tests/test_psi.rs`（或改为 cfg(false) skip，但简单删除更好）
   - `rm tests/test_ebpf_flow.rs`（如果存在）
   - `rm src/ebpf/ebpf-ebpf/Cargo.toml` + 子项目（workspace member 已在 stage 1 移除）

2. **清理 src/ 内 cfg gate**（~25 文件，按 audit 报告逐个处理）
   - 典型文件：`src/collect.rs` / `src/inspect/{env,dlls,handles,memory}.rs` / `src/dns_log/mod.rs` / `src/disk_io_etw/mod.rs` / `src/schannel_etw/mod.rs` / `src/gpu.rs` / `src/net_flow/mod.rs` / `src/security/{dll_check, privilege}.rs` / `src/process_control.rs` / `src/kill.rs` / `src/eject/mod.rs` / `src/throttle.rs` / `src/app_group.rs` / `src/classify.rs` / `src/estats.rs` / `src/lib.rs` 等
   - 策略：删除 `#[cfg(not(target_os = "windows"))]` 块；删除 `#[cfg(target_os = "linux")]` 块；保留 `#[cfg(target_os = "windows")]` 块（去掉 cfg attr，因为现在所有平台都是 Windows）
   - 关键关注点：
     - `src/collect.rs`：sysinfo 跨平台保留（sysinfo 自身处理 Windows），但 per-core 频率 / 温度的 Linux 路径（`/sys/devices/system/cpu/cpufreq` + hwmon）删除
     - `src/inspect/{env,dlls,handles,memory}.rs`：Linux stub 分支删除（`/proc/<pid>/environ` / `/proc/<pid>/maps` / `/proc/<pid>/fd`）
     - `src/gpu.rs`：NvtopProvider（Linux nvtop 子进程）删除；NvmlProvider（Windows）保留
     - `src/net_flow/mod.rs`：NethogsCollector（Linux）删除；IphelperCollector（Windows）保留
     - `src/throttle.rs`：EcoQoS（Windows）保留；Linux cgroup 注释删除
     - `src/dns_log/mod.rs`：Linux 返 None 分支删除；保留 Windows detect_collector
     - `src/schannel_etw/mod.rs`：非 Windows `try_spawn_probe` 返 None 分支删除

3. **清理 src/cli/ + src/app.rs + src/mcp/ 内 Linux 引用**
   - `src/cli/flows.rs`：移除 `EBPF_ENABLED` 检查 + `ebpf_worker.is_none()` 分支（FlowSource 仅 Schannel）
   - `src/cli/def.rs`：移除任何 Linux-only 参数（如有）
   - `src/app.rs`：移除 `tick_flows_ebpf` 方法 + `flow_aggregator` 字段 + `App::workers.ebpf_worker` 字段
   - `src/app_panel.rs`：PanelContext 中 flows 字段保留（FlowSource 仍存在，只是只有 Schannel 变体）
   - `src/mcp/handler.rs`：移除任何 ebpf 路径
   - `src/view_models/port_panel.rs`：Flow view 仍工作（基于 Schannel）

4. **ProcessFlow 简化（src/ebpf/flow.rs 已删 → 新位置 src/flow.rs 或 src/schannel_etw/flow.rs）**
   - ProcessFlow 数据结构保留（CLI flows / port_panel flow view 都依赖）
   - 移到 `src/flow.rs`（新文件）或合并到 `src/schannel_etw/mod.rs`
   - FlowSource enum 从 `{ Ebpf, Schannel }` 简化为单变体 `Schannel`（或直接删 FlowSource，ProcessFlow.source 字段移除）
   - **surgical 选择**：直接删 FlowSource enum + ProcessFlow.source 字段（serde `#[serde(default)]` 保旧录屏兼容）；用户视角「来源」列不再显示（只有一个来源）
   - 修订所有使用 `FlowSource::Ebpf` / `f.source == FlowSource::Ebpf` 的代码（约 8-10 处）

5. **删 `EBPF_ENABLED` 常量**（src/ebpf/mod.rs 已删，常量也删）
   - grep `EBPF_ENABLED` 全仓库，删除所有引用（~5 处）

6. **清理 Cargo.toml**（stage 1 已删 feature flag，本阶段补完）
   - 删 `[target.'cfg(windows)'.dependencies.nvml-wrapper]` 的 cfg target 包裹（直接作为 optional dep）—— **或保留 cfg target**（更安全，未来若加回 macOS 不会重新引依赖）
   - 删 `[target.'cfg(not(target_os = "windows"))'.dependencies]` 段（stage 1 应已删，本阶段二次确认）
   - 删 Rust toolchain nightly 引用（README / CONTRIBUTING / .github/workflows/）

7. **更新 .github/workflows/**
   - `ci.yml`：删 `check-linux` job（Linux 上跑 cargo test 的 job）
   - `release.yml`：删 `linux-musl` / `linux-arm` / `linux-ebpf` target build step；保留 5 个 target 中 `x86_64-pc-windows-msvc`，其他 macOS target 评估是否保留（用户决策：本 cycle 完全 Windows-only，删 macOS target）
   - 删 `proc_ebpf` 后缀二进制构建步骤

8. **更新 README.md**
   - banner 加 v0.12.0 段（Windows-only 决策 + UX polish 摘要）
   - 「平台支持」表：删 Linux / macOS 列，仅保留 Windows

   - 加新术语：v0.12 平台决策段
   - 「术语演进历史」加 v0.12.0 阶段 2 行（记录这次大重构）
