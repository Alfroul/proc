## 调查发现（本会话开工取材，2026-09-01）

### 深挖①证据源修正：ADR-0003 是幽灵引用（「PID 复用键控」证据改用代码层真实锚）

ADR-0036 D4 清单①「PID 复用键控（(pid, start_time) 元组）｜ADR-0003」——**现行 ADR-0003 实际是 smartctl 子进程选型**（`0003-smart-subprocess-vs-library.md`，v0.5.0 阶段 5）；git 全历史查证 `docs/adr/0003-pid-reuse-start-time-key.md` **从未存在**（`git log --all` 零命中，现 0003 文件 v0.6.0 阶段 1 才入仓）。同一幽灵引用还出现在 `src/app.rs:181` 注释 / CONTEXT.md PID 词条 / ADR-0021 Related 段。**(pid, start_time) 键控的真实代码证据**（深挖①改用，D5 纪律）：

- `src/app.rs:181-182`：`prev_process_disk: HashMap<(u32, u64), (u64, u64)>`（TUI disk 速度差分键控）
- `src/security/score.rs:50-56/417-420`：alive 缓存键 `{pid}:{start_time}:{exe}` + `invalidate_dead(&HashSet<(u32, u64)>)`
- `src/mcp/handler/mod.rs:299/361-394`：TD-53 worker delta 同款键控（v0.25 stage 3，含「PID 复用键控」单测）
- `src/tui/detail_view.rs:718-727`：Inspector「同一进程」解析按 (pid, start_time) 元组
- `src/net_flow/mod.rs:37` + `src/dns_log/mod.rs:30` + `src/flow.rs:21`：flow 身份 (pid, start_time) → 远端二元组
- 反例边界（诚实叙事素材）：`process_cache: HashMap<u32, ProcessInfo>`（collect.rs:1351）本体单键 pid + in-place 易变字段更新（省 alloc 权衡）；TD-21 overlay 单键 pid 维持归档（窗口窄）；ADR-0005 netflow PID 复用已知限制

处置：深挖①如实写「代码层证据 + ADR-0021/0016 历史引用」，标注幽灵引用现象本身（REVIEW-v0.26 记 P2 doc finding，修复——四处引用点改指代码锚——随本阶段 doc 类小修搭车或留 v0.27，按规模定）。
