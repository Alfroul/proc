#### TD-16：FilterExpr 错误信息中文化（1-2 h）

6. **写 ErrorKind → 中文映射表**（`src/filter/parser.rs`）
   - 现状：`to_parse_error` 直接 `format!("expected {:?}", ErrorKind::TakeWhile1)`
   - 改为：match ErrorKind → 中文字符串
     ```rust
     fn error_kind_to_chinese(kind: &nom::error::ErrorKind) -> &'static str {
         match kind {
             ErrorKind::TakeWhile1 => "缺少字段名/值",
             ErrorKind::Tag => "缺少关键字/操作符",
             ErrorKind::Verify => "正则编译失败",
             ErrorKind::Float => "数字格式错误",
             ErrorKind::Char => "缺少字符",
             ErrorKind::Alpha => "缺少字母",
             ErrorKind::Digit => "缺少数字",
             _ => "语法错误",
         }
     }
     ```
   - `to_parse_error` 改用映射表：`msg: error_kind_to_chinese(&e.code).to_string()`

7. **更新测试断言**
   - `tests/test_filter_expr.rs` 里所有错误信息断言从 `assert!(msg.contains("TakeWhile1"))` 改 `assert!(msg.contains("缺少"))`
   - 加新 case：`cpu >` → msg 含「缺少值」；`name =` → msg 含「缺少值」；`(cpu > 5` → msg 含「括号」
