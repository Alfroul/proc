### 阶段 6：可疑路径 R18（malware 启动位置）

> ✅ **已完成**（v0.11.0 阶段 6 会话产出，2026-06-29；commit 引用见 CONTEXT.md「术语演进历史」段）

> **独立会话指令**：`阅读 CONTEXT.md 和 docs/stages/v0.11-stage-6.md，完成所有任务后确认完成`

**目标**：实装 R18 安全规则——进程 `.exe` 路径在 `%TEMP%` / `%APPDATA%` / `%LOCALAPPDATA%` / 用户新建目录扣分。配合 R16（未签名）双重过滤准确度高（LOLBAS 攻击 / Living Off The Land Binaries and Scripts 常见模式）。

**前置依赖**：阶段 4 已完成（R16 签名验证就位——R18 与 R16 协同效果好；不依赖阶段 5 但同期落地）。

**依赖测试**（开工时跑这些测试的详情）：
- `cargo test --release --test test_security -- --nocapture`（v0.6/v0.7/v0.11 阶段 4/5 安全评分框架契约）

**任务清单**：

1. **路径规则实装**（`src/security/path_rules.rs` 新）
   - `pub fn expand_user_dir(env_var: &str) -> Option<PathBuf>`
   - `pub fn is_in_suspicious_path(exe_path: &Path, user_dirs: &UserDirs) -> Option<SuspiciousPathKind>`
   - `SuspiciousPathKind` enum：`Temp` / `AppData` / `LocalAppData` / `UserProfileDownloads` / `Custom`（用户配置）
   - 默认可疑目录列表：
     - `%TEMP%`（`C:\Users\{user}\AppData\Local\Temp`）
     - `%APPDATA%`（`C:\Users\{user}\AppData\Roaming`）
     - `%LOCALAPPDATA%`（`C:\Users\{user}\AppData\Local`）
     - `%USERPROFILE%\Downloads`（浏览器默认下载目录）
   - 不标记：`Program Files` / `Windows` / `System32`（系统目录，签名进程正常）
   - 大小写不敏感匹配（Windows 路径不区分大小写）
   - 环境变量展开用 `std::env::var(env_var)` + 路径前缀匹配

2. **R18 规则实装**（`src/security/score.rs`）
   - 加 `check_path_risk(procs: &[ProcessInfo]) -> Vec<RiskFactor>`
   - 对每个进程：调 `is_in_suspicious_path`
   - 命中 `Temp` → 扣 20 分（malware 最爱）
   - 命中 `AppData` / `LocalAppData` / `UserProfileDownloads` → 扣 15 分（合法应用也可能放这，如便携应用）
   - 命中 `Custom` → 按用户配置 weight
   - **协同扣分规则**：同时命中 R16（未签名）+ R18（可疑路径）→ 额外扣 10 分（双重特征强信号）
   - R18 加到 `SecurityScorer::score` 第 18 步（v0.11 阶段 4 R16 + 阶段 5 R17 + 阶段 6 R18 = 18 项评分）

3. **配置文件支持**（`~/.config/proc/path_rules.toml` 可选）
   - 默认不存在 → 只用内置 4 种可疑目录
   - 用户显式创建 → 加自定义目录（如 `%USERPROFILE%\Desktop\Suspicious`）
   - 格式示例：
     ```toml
     [[suspicious_dir]]
     path = "%USERPROFILE%\\my_suspicious_dir"
     weight = 25
     reason = "用户标记的可疑目录"
     ```

4. **UI 显示**（`src/tui/detail_view.rs`）
   - Inspector Summary Tab 加「启动路径: {exe_path} [⚠ 可疑位置]」标记
   - 命中 R18 时 Inspector 顶部显示橙色警告「⚠ 可疑启动路径：%TEMP%」

5. **测试**（`tests/test_path_rules.rs` 新）
   - 单元：`expand_user_dir("TEMP")` 返回正确 PathBuf
   - 单元：`is_in_suspicious_path` 命中 Temp（mock `C:\Users\xxx\AppData\Local\Temp\evil.exe`）
   - 单元：`is_in_suspicious_path` 命中 AppData
   - 单元：`is_in_suspicious_path` 不命中 Program Files（合法目录）
   - 单元：大小写不敏感匹配（`c:\users` vs `C:\Users`）
   - 单元：环境变量未设置时返回 None（如 Linux 上 `%TEMP%` 不存在）
   - 单元：R18 规则扣分（20 / 15 两档）
   - 单元：R16 + R18 协同扣分（额外 10 分）
   - 集成：mock ProcessInfo exe path → BackgroundScorer 评分变化

6. **CONTEXT.md 更新**
   - 加术语：SuspiciousPathKind / UserDirs / path_rules.toml / R18
   - 术语演进历史加 v0.11.0 阶段 6 行
