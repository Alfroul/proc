### 阶段 3：功能 Slice — Shell completion + 命令面板 Ctrl+P

> ✅ **v0.7.0 已发布（2026-06-28）**。本阶段任务全部交付，详见 CHANGELOG `[0.7.0]` 段「阶段 3」。

> **独立会话指令**：`阅读 CONTEXT.md 和 docs/stages/v0.7-stage-3.md，完成所有任务后确认完成`
>
> **开工前只需阅读**：`CONTEXT.md`（CommandPalette / AppLayer 术语）、`docs/stages/v0.7-stage-3.md`、测试命令、`docs/adr/0010-shell-completion-and-palette.md`（本阶段产出）。

**目标**：
1. Shell completion：`proc completions --shell <bash/zsh/fish/powershell>` 子命令 + release CI 打包
2. 命令面板 Ctrl+P：基于 nucleo fuzzy 库的 ratatui 浮层，解决键位爆炸问题（6 面板 × 6 Tab × 17+ 子命令）

**前置依赖**：阶段 2 已完成（命令面板会列出 MCP 命令作为可选项）。

**依赖测试**（开工时跑详情）：

- `cargo test --release --test test_mcp_server -- --nocapture`（阶段 2 新增）
- `cargo test --release --test test_inspector -- --nocapture`（v0.6 键位基线，命令面板不能破坏）

**技术决策（详见 ADR-0010）**：

- **Shell completion**：用 `clap_complete 4`（最标准）。`build.rs` 不用（避免编译时耦合），用 `proc completions --shell <SHELL>` 在线生成子命令。
- **命令面板 fuzzy**：用 `nucleo`（Helix 编辑器出品，性能极佳，rust-code 已验证可行）
- **TUI 输入框**：用 `tui-input 0.15`（150 万下载，标准）
- **AppLayer 状态机**：新增 `enum AppLayer { Normal, Search, Palette }`，App::handle_key 先 dispatch layer，layer 决定按键派给谁

**任务清单**：

#### Part A：Shell completion（~0.5 天）

1. **依赖添加（5 min）**
   - `Cargo.toml` `[dependencies]` 加：`clap_complete = "4"`
   - 验证：`cargo build --release` 通过

2. **CLI subcommand 注册（30 min）**
   - `src/cli/def.rs` 在 `Command` enum 加：
     ```rust
     #[command(name = "completions", about = "Generate shell completions")]
     Completions {
         /// Target shell: bash / zsh / fish / powershell / elvish
         #[arg(long, short)]
         shell: clap_complete::Shell,
     },
     ```
   - `src/cli/completions.rs`（新增）：
     - `pub fn run_completions(shell: clap_complete::Shell) -> anyhow::Result<()>`
     - 调 `clap_complete::generate(shell, &mut cmd, "proc", &mut std::io::stdout())`
     - cmd 用 `crate::cli::Cli::command()` 重新构造（不消耗现有 parser）
   - `src/cli/mod.rs::run_subcommand` 加 dispatch
   - 验证：`proc completions --shell bash` 输出 completion 脚本到 stdout

3. **预生成 completion 文件（30 min）**
   - 新建 `completions/` 目录
   - 各跑一次：`cargo run --release -- completions --shell bash > completions/proc.bash`
   - 同样生成 `completions/proc.zsh` / `completions/proc.fish` / `completions/_proc.ps1`
   - 验证：4 个文件存在，`head completions/proc.bash` 看到合理的 bash completion

4. **release CI 打包 completion（30 min）**
   - `.github/workflows/release.yml` 在 build step 后追加：copy `completions/` 到 `proc-${{ matrix.target }}/`
   - 或新建 `.github/workflows/completions.yml` 在 tag push 时把 4 个 completion 文件作为额外 artifact 上传到 Release
   - winget / scoop manifest 加 completion 文件路径（如 scoop 默认装到 `$dir/completions/`）
   - 验证：在 PR 上手动触发 release workflow 看产物含 completions

5. **README + scoop manifest 同步（15 min）**
   - README「安装」段加："shell completion：从 Release 下载 `completions/proc.<shell>` 放到 `~/.bash_completion.d/`（或对应 shell 路径）"
   - `scoop/proc.json` 加 `"architecture"` 段（如需要）或 `bin` 段补 completions
   - 验证：README 含 completion 安装说明

#### Part B：命令面板 Ctrl+P（~2 天）

6. **依赖添加（5 min）**
   - `Cargo.toml` 加：`nucleo = "0.5"` + `tui-input = "0.15"`
   - 验证：`cargo build --release` 通过

7. **AppLayer 状态机（1 h）**
   - `src/app.rs`（或 `src/app_panel.rs`）新增：
     ```rust
     #[derive(Default, Clone, Copy, PartialEq)]
     pub enum AppLayer {
         #[default]
         Normal,
         Search,    // 已有的搜索框，单独提一层
         Palette,   // 新增 Ctrl+P 命令面板
     }
     ```
   - `App::active_layer: AppLayer` 字段
   - `App::handle_key` 入口先 match active_layer，决定 dispatch 路径
   - v0.6 的 search 状态机：`SearchState::active == true` 时 → AppLayer::Search
   - 验证：v0.6 现有搜索行为不变（搜索时按 `1`-`6` 不切面板）

8. **命令面板状态 + 项注册（2 h）**
   - 新建 `src/tui/command_palette.rs`：
     ```rust
     pub struct CommandPalette {
         pub input: tui_input::Input,
         pub items: Vec<CommandItem>,
         pub matched: Vec<usize>,  // nucleo matcher 输出
     }

     pub struct CommandItem {
         pub id: &'static str,        // "kill_cursor" / "switch_to_port_panel"
         pub label: &'static str,     // "Kill cursor process"
         pub category: &'static str,  // "Process" / "Panel" / "Docker"
         pub hint: &'static str,      // "k"（快捷键）
         pub action: CommandAction,
     }

     pub enum CommandAction {
         KillCursor,
         KillGroup,
         SwitchPanel(usize),
         SwitchTab(crate::inspect::InspectionTab),
         ToggleAppGroup,
         ToggleRecord,
         StartMonitor,
         RunMcp,
         // ... 每个面板的常用动作都注册一个
     }
     ```
   - 项数量：约 30-50 个（覆盖 v0.6 所有键位 + 阶段 2 新增 MCP）
   - 验证：grep `CommandItem {` 应 ≥ 30 处

9. **命令面板 UI 渲染（2 h）**
   - ratatui 浮层（用 `Clear` + `Block`），居中显示
   - 顶部：输入框（tui-input）+ prompt `❯`
   - 中部：匹配列表（前 10 项），高亮当前选中
   - 底部：当前项的 hint + category
   - nucleo matcher 实时跑（每次输入触发）：items.score(&input.value())，按 score 排序取前 10
   - 验证：手动启动 TUI 按 Ctrl+P 看浮层渲染

10. **命令面板 handle_key（1 h）**
    - Ctrl+P → 激活：`active_layer = Palette`
    - Esc → 取消，回到 Normal
    - Enter → 执行 action，回到 Normal
    - ↑↓ → 移动选中
    - 字符键 → 喂 input
    - Ctrl+P 激活时其他按键都被拦截，不传给面板/搜索/详情页
    - 验证：测试覆盖（见任务 12）

11. **App::handle_key dispatch 重构（1 h）**
    - 入口处先 check layer：
      ```rust
      match self.active_layer {
          AppLayer::Palette => {
              if let Some(action) = self.command_palette.handle_key(key) {
                  self.dispatch_command_action(action);
              }
              return;
          }
          AppLayer::Search => { /* v0.6 已有 search 路径 */ }
          AppLayer::Normal => { /* v0.6 已有 normal 路径 */ }
      }
      ```
    - `dispatch_command_action` 实现 CommandAction 到具体副作用（kill / switch_panel / ...）
    - 验证：所有 v0.6 现有测试仍通过

12. **集成测试 `tests/test_command_palette.rs`（2 h）**

    - 测试 2：Palette 状态输入 "kill" → matched 项数 ≤ items.len()，且匹配的项 label 含 kill
    - 测试 3：Palette 状态按 Esc → active_layer 变 Normal
    - 测试 4：Palette 状态按 Enter → 执行 action 后 active_layer 变 Normal
    - 测试 5：Palette 状态按 `1`-`6` → 不切面板（被拦截）
    - 测试 6：v0.6 现有搜索 `/` 触发 → active_layer 变 Search
    - 测试 7：Search 状态按 Ctrl+P → active_layer 变 Palette（搜索中断）
    - 验证：7 个测试全部通过
