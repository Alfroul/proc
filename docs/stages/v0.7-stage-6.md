> ✅ **v0.7.0 已发布（2026-06-28）**。本阶段任务全部交付，详见 CHANGELOG `[0.7.0]` 段「阶段 6」。

>
> **开工前只需阅读**：`CONTEXT.md`（PsiStats / EcoQoSState 术语）、`docs/stages/v0.7-stage-6.md`、测试命令。

**目标**：两个独立的平台专项功能合到一个 slice（都不大，单独成阶段太碎）：

1. **Linux PSI（Pressure Stall Information）监控**：读 `/proc/pressure/{cpu,mem,io}`，监控面板加 3 个仪表 + alerts.toml 加 MemoryPressure 规则
2. **Windows 11 EcoQoS 切换**：`SetProcessInformation` + `PROCESS_POWER_THROTTLING_STATE`，CLI `proc throttle <pid> on|off` + 进程列表 🍃 标记

**前置依赖**：阶段 5 已完成（App 已拆 controller，新功能加在 controller 内）。

**依赖测试**（开工时跑详情）：

- `cargo test --release --test test_panel_controllers -- --nocapture`（阶段 5 基线，验证 ProcessPanelController 接口稳定）
- `cargo test --release --test test_alert -- --nocapture`（v0.6 alert 基线，PSI 要加新规则）
- `cargo test --release -q`（全量基线）

**技术决策**：

- **PSI 不引依赖**：直接手写 parser 读 `/proc/pressure/{cpu,mem,io}`（格式简单：`some avg10=X avg60=Y avg300=Z total=T\nfull ...`），不引 `psi` crate 也不引 `procfs-core`。理由：parser 50 行，依赖 > 50 行；procfs-core 拖大量额外功能
- **PSI 跨平台 cfg-gate**：Linux 平台编译 PSI 模块；Windows / macOS 编译 stub（返回 None），监控面板降级显示 "PSI: Linux 4.20+"
- **EcoQoS 直接用 windows-rs**：不引 `win32-ecoqos` crate。理由：3 行 FFI 自己写更可控，且 windows-rs 已是依赖
- **EcoQoS 也支持查询**：除了 set，还要能 read（"这个进程当前是否被系统自动 throttle"），用于进程列表 🍃 标记。读路径走 `NtQueryInformationProcess`（undocumented 但 System Informer 在用）

详见 `docs/adr/0013-psi-monitoring.md` 和 `docs/adr/0014-ecoqos-throttle.md`。

1. **新建 `src/psi.rs`（1 h）**
   - cfg-gate：`#[cfg(target_os = "linux")]` 实装，其他平台 stub
   ```rust
   #[derive(Debug, Clone, Default, serde::Serialize)]
   pub struct PsiRecord {
       pub avg10: f32,
       pub avg60: f32,
       pub avg300: f32,
       pub total: u64,
   }

   #[derive(Debug, Clone, Default, serde::Serialize)]
   pub struct PsiStats {
       pub cpu_some: PsiRecord,    // CPU 只有 some，没 full
       pub mem_some: PsiRecord,
       pub mem_full: PsiRecord,
       pub io_some: PsiRecord,
       pub io_full: PsiRecord,
   }

   #[cfg(target_os = "linux")]
   pub fn read_psi() -> Option<PsiStats> {
       let cpu = read_psi_file("/proc/pressure/cpu")?;
       let mem = read_psi_file("/proc/pressure/memory")?;
       let io = read_psi_file("/proc/pressure/io")?;
       Some(PsiStats {
           cpu_some: cpu.0,  // CPU 只有 some
           mem_some: mem.0,
           mem_full: mem.1,
           io_some: io.0,
           io_full: io.1,
       })
   }

   #[cfg(not(target_os = "linux"))]
   pub fn read_psi() -> Option<PsiStats> { None }
   ```
   - `read_psi_file` 解析 2 行（some / full），每行 4 个 key=value

#### Part B：EcoQoS 切换（Win11）— ~半天

7. **新建 `src/throttle.rs`（1 h）**
   - cfg-gate：`#[cfg(windows)]` 实装，其他平台 stub
   ```rust
   #[derive(Debug, Clone, Copy, PartialEq, serde::Serialize)]
   pub enum EcoQoSState {
       Normal,    // 不 throttle
       Eco,       // throttle on（绿叶）
       Unknown,
   }

   #[cfg(windows)]
   pub fn set_throttle(pid: u32, eco: bool) -> anyhow::Result<()> {
       use windows::Win32::System::Threading::*;
       unsafe {
           let h = OpenProcess(PROCESS_SET_INFORMATION | PROCESS_QUERY_LIMITED_INFORMATION, false, pid)?;
           let mut state = PROCESS_POWER_THROTTLING_STATE {
               Version: PROCESS_POWER_THROTTLING_CURRENT_VERSION,
               ControlMask: PROCESS_POWER_THROTTLING_EXECUTION_SPEED,
               StateMask: if eco { PROCESS_POWER_THROTTLING_EXECUTION_SPEED } else { 0 },
           };
           SetProcessInformation(
               h,
               ProcessPowerThrottling,
               &mut state as *mut _ as *mut _,
               std::mem::size_of::<PROCESS_POWER_THROTTLING_STATE>() as u32,
           )?;
           let _ = CloseHandle(h);
       }
       Ok(())
   }

   #[cfg(windows)]
   pub fn query_throttle(pid: u32) -> EcoQoSState {
       // 用 SetProcessInformation 用 mask=0 查询当前状态
       // 或读 NtQueryInformationProcess ProcessPowerThrottling（undocumented）
   }
   ```
